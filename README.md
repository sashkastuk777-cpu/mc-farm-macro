# mc-farm — макрос фарма мобов для Minecraft

Макрос для ванильного сервера (play.workahop47.pro, режим «2 этап»): сам бегает,
водит прицелом и не перестаёт стрелять, чтобы набирать большое комбо.

## Установка
1. Скачай **mc-farm.exe** (кнопка «Download raw file»).
2. Запусти двойным кликом. В трее появится иконка «H».
3. Открой Minecraft, встань на зону спавна мобов.

## Управление
- **F6** — полный фарм: бег + обзор + стрельба
- **F7** — только стрельба (стоишь на месте, сам целишься)
- **F8** — аварийный стоп, отпускает все клавиши
- **F9** — калибровка цвета зомби (см. ниже)
- **F5** — смена камеры; блокируется, пока макрос включён

Выход: F8, затем клик по иконке в трее → Exit.

## Стрельба только по зомби
По умолчанию макрос стреляет во всё подряд. Чтобы клики шли только когда под
прицелом реально стоит зомби, откалибруй цвет — один раз:

1. Включи макрос (**F6** или **F7**) и наведи прицел на **зелёный участок кожи зомби**.
2. Нажми **F9**. Появится подсказка с цветом, например `0x5A8A3C`.
3. Готово — цвет сохранился в `mc-farm.ini` рядом с `mc-farm.exe`, фильтр включился.

Дальше выстрел уходит только если в зоне ±45 px вокруг прицела есть похожий цвет.
Пока калибровки нет, фильтр **выключен** — макрос стреляет как раньше, и при
запуске показывается предупреждение с просьбой нажать F9.

Фильтр можно выключить, не пересобирая: открой `mc-farm.ini` и поставь
`Only=false`.

### Настройки в mc-farm.ini
Создаётся после первого нажатия F9, правится любым текстовым редактором:

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `Color` | `0x00A800` | цвет зомби, пишется автоматически по F9 |
| `Only` | `true` | включить/выключить фильтр |
| `Box` | `45` | полуразмер зоны проверки вокруг прицела, px |
| `Tolerance` | `42` | допуск цвета, 0–255; больше — мягче, но больше ложных срабатываний |

## Настройки (в mc-farm-macro.ahk, вверх файла)
- `FireStyle := "hold"` — если оружие стреляет зажатой ЛКМ, а не кликами.
- `AimDownSights := true` — если стрельба идёт с прицеливанием на ПКМ.
- `ClickMin / ClickMax` — пауза между выстрелами (мс). Кикает за автокликер? Подними до 130–180.
- `SweepMin / SweepMax` — скорость обвода прицелом.

Эти значения доступны только в исходнике — для .exe они вшиты при сборке.

## Исправлено
- **Залипание клавиш при потере фокуса** — при переключении из игры W/Ctrl/ЛКМ
  оставались нажатыми и уходили в другое окно.
- **Клавиша движения и спринт не отпускались при F6 → F7** — переход из «фарма»
  в «только стрельба» оставлял их зажатыми.
- **Очистка при выходе** (`OnExit`) — закрытие макроса больше не оставляет
  нажатые клавиши.
- **Режим `hold` не отпускал ЛКМ** при останове.

## Важно
- Макрос **не читает память игры** и не распознаёт сущностей. Режим «только зомби»
  работает по **цвету пикселей** под прицелом — поэтому трава, листва или зелёный
  скин другого игрока дадут ложное срабатывание. Точность зависит от калибровки,
  `Box` и `Tolerance`. Настоящее распознавание мобов этим способом недоступно.
- Работает лучше на открытой зоне спавна.
- Windows Defender может ругаться на скомпилированный AHK-скрипт — это
  ложное срабатывание: «Сведения» → «Всё равно запустить».
- Автокликеры/макросы могут нарушать правила сервера. Используй на свой риск.
